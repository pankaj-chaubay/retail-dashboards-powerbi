# Original Tableau workbooks

The workbooks I submitted for the M.Sc. module "Visualization and Story Telling using Tableau" (Berlin School of Business and Innovation, 2025).

- `Customer Behaviour Dashboard.twb`: practical assessment, retail customer behaviour. Published on [Tableau Public](https://public.tableau.com/views/CustomerBehaviourDashboard_Final/CustomerDashboardCategoryRegion).
- `Superstore Sales Dashboard.twb`: project output, advanced sales dashboard on Sample Superstore.

Open them in Tableau Desktop or Tableau Public and point the data source to the CSVs in `../data`.
